# MultiCapture

Webで公開されている動画（大学の講義アーカイブなど）を、**複数のブラウザで区間を分けて同時に再生・録画し、1本の動画にまとめる**Windows 11用ツールです。たとえば4つに分ければ、2時間の動画を約30分で録画できます。

複数のWebページを同時に開き、それぞれの映像と音声を別々のファイルに録画することもできます（「ページを同時録画」タブ）。

- インストールは不要です。ZIPを展開して `MultiCapture.exe` を起動するだけで使えます
- 仮想オーディオケーブルなどの追加ソフトも不要です。ブラウザごとに音声を直接取り出します
- ログインが必要なサイトにも対応しています（最初に1回ログインすれば、録画用のブラウザすべてに引き継ぎます）
- 録画中のブラウザは重なっていても、他のアプリの裏に隠れていても録画できます

> **録画してよい動画かどうかは、必ず確認してください。** 著作者（講義なら担当教員）から録画やダウンロードの許可を得ている動画に使ってください。コピー防止（DRM）がかかった有料配信は、真っ黒に録画されます。DRMを回避する機能はありません。

## 動作環境

- Windows 11（ブラウザごとの音声取得APIがWindows 11以降でしか使えないため、Windows 10では動きません）
- Microsoft Edge（Windows 11に標準搭載）または Google Chrome
- GPUエンコーダ（NVIDIA / AMD / Intel）があれば自動で使用し、ない場合はCPUでエンコードします

## 使い方：講義動画を高速録画

1. ZIPを展開し、`MultiCapture.exe` を起動します
   - 初回起動時に「WindowsによってPCが保護されました」と表示された場合は、「詳細情報」→「実行」を押してください（署名なしアプリのため表示されます）
2. 「講義動画を高速録画」タブで、**動画が再生されるページのURL**を入力します
3. ログインが必要なサイトでは、「ログイン用ブラウザを開く」を押して、開いたブラウザでログインし、動画が表示されるところまで進めます（ブラウザは開いたままで構いません）
4. 「同時に録画する数」を選び（初期値は4）、「● 高速録画開始」を押します
5. 区間ごとの進み具合と残り時間が表示されます。完了すると、保存先フォルダ（初期設定は `ビデオ\MultiCapture`）に `動画ページのタイトル_日時.mp4` が保存されます

### 補足

- **「動画部分だけを録画する」**（初期設定でオン）：ページのヘッダーやメニューを隠し、動画を画面いっぱいに表示して録画します。動画を2つ並べて表示するプレーヤーなど、うまく表示されない場合はオフにすると、ページ全体を録画します
- **「録画中はPCの音をミュート」**（初期設定でオン）：複数の区間が同時に鳴らないように、録画中はPCのスピーカーをミュートします。録画ファイルには音声が正しく入ります。録画が終わると元の状態に戻ります（アプリが途中で落ちた場合も、次回起動時に元に戻します）
- **読み込みが止まった場合**：通信が遅くて動画が止まると、その間は録画も止め、再生が戻ったら止まった位置まで巻き戻して録画を再開します。内容が抜けることはありませんが、0.2秒ほど静止する箇所が入ることがあります
- **同時に録画する数の目安**：数を増やすほど速くなりますが、そのぶん通信量とPCの負荷が増えます。動画が頻繁に止まる場合は数を減らしてください。サービスによっては、同時に再生できる数に制限があります
- **画面の大きさ**：画面より大きい録画サイズを指定した場合は、表示できる最大サイズで録画し、指定サイズに拡大して保存します

## 使い方：ページを同時録画

複数のページ（ダッシュボードなど）を開き、それぞれをリアルタイムで、ページごとに別のファイルとして録画します。

1. 「ページを同時録画」タブで「追加」を押し、名前・URL・録画サイズを登録します
2. 「ブラウザを開く」を押し、必要ならログインします（ログイン状態はページごとに保存され、次回以降も使えます）
3. 「● 録画開始」を押し、終わったら「■ 録画停止」を押します

起動オプションを付けると、起動と同時に録画を始め、指定した秒数で保存して終了します（タスクスケジューラ向け）。

```
MultiCapture.exe --start --duration 3600
```

## 共通の注意事項

- 録画中のブラウザは**最小化しないでください**（最小化するとWindowsが描画を止めるため、映像が止まります）
- 録画中はWindowsの自動スリープを止めます。画面が消えても、PCがロックされても録画は続きます。画面も消したくない場合は「録画中は画面をオフにしない」にチェックを入れてください
- ノートPCのふたを閉じたり、手動でスリープにした場合は、録画が中断します
- 録画用のブラウザは、普段使っているブラウザとは別の専用プロファイルで起動します。普段のブラウザの設定や履歴には影響しません。Microsoftアカウントへの自動サインインと同期は無効にしています
- 設定、ログイン情報、ログは `MultiCapture.exe` と同じフォルダの `data` フォルダに保存されます（書き込めない場所の場合は `%LOCALAPPDATA%\MultiCapture`）

## しくみ

| 処理 | 使用している技術 |
|---|---|
| ブラウザの操作（再生位置の移動、動画の検出、ログイン情報の引き継ぎ） | Chrome DevTools Protocol |
| 映像キャプチャ | Windows Graphics Capture |
| 音声キャプチャ | WASAPIのプロセスループバック（ブラウザのプロセス単位） |
| バックグラウンドでの描画維持 | Chromiumの起動オプション |
| エンコードと結合 | FFmpeg（NVENC / AMF / QSV / x264 から自動選択） |

## 開発者向け

Python 3.10以上があれば、ソースからそのまま起動できます。標準ライブラリだけで動作し、追加パッケージは不要です。

```
python -m multicapture
```

FFmpegは、`ffmpeg\ffmpeg.exe`、`ffmpeg.exe`（どちらもアプリと同じ場所）、PATHの順に探します。

### 配布用ZIPの作成

```
powershell -ExecutionPolicy Bypass -File build.ps1 -DownloadFFmpeg
```

`dist\MultiCapture-<version>-win64.zip` が生成されます。`-DownloadFFmpeg` を指定すると、gyan.devのessentialsビルドをダウンロードして同梱します。代わりに `-FFmpeg <path>` で手元のffmpeg.exeを指定することもできます。

### ライセンス

同梱しているFFmpegはGPLライセンスです。ライセンス文は `ffmpeg\` フォルダに含まれています。
